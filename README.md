# NeuroQueer Voice Homepage

This is the first page of the NeuroQueer Voice & Resonance Liberation website.

## Publish with GitHub Pages

1. Create a **public** repository named exactly:
   `neuroqueervoice.github.io`

2. Upload the following items from this folder:
   - `index.html`
   - `assets` folder
   - `README.md`

3. Open the repository's **Settings**.

4. In the left sidebar, select **Pages**.

5. Under **Build and deployment**:
   - Source: **Deploy from a branch**
   - Branch: **main**
   - Folder: **/(root)**

6. Click **Save**.

Your website address will be:

`https://neuroqueervoice.github.io`

GitHub may take several minutes to publish the first version.
